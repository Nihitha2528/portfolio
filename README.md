# Personal Portfolio Website

A simple, responsive personal portfolio website built with pure HTML and CSS. Designed specifically for students to showcase their current learning journey, foundational skills, and contact information without needing completed projects.

---

## 🚀 Features

- **About Me**: Brief introduction and academic focus.
- **Skills**: Badges showcasing programming languages and tools.
- **Learning & Labs**: Highlights current coursework, practice topics, and upcoming project goals instead of traditional portfolio items.
- **Contact & Socials**: Quick links to reach out via email, GitHub, or LinkedIn.
- **Pure CSS**: Fully responsive with zero external frameworks or JavaScript dependencies.
